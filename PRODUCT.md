# CreatorAI

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Creators turning an idea and uploaded footage into reviewable short-form content.
Brand collaborations use saved campaign requirements and reusable creator style.
Solo-creator prioritization is inferred from the approved hackathon baseline;
the user delegated recommended choices and requested the entire frontend.

## Product Purpose

Connect brief, scripts, private source assets, grounded clips, explicit edits,
verified platform exports, manual publication tracking and sourced insights in
one workspace. Success means completing that workflow without losing originals,
drafts or immutable saved versions.

## Positioning

CreatorAI links script sections to timestamped speech and visual evidence, keeps
editable source recipes, and verifies exported MP4 files before package approval.
Creators review AI proposals; AI does not silently apply changes or publish.

## Operating Context

Existing Next.js App Router application with FastAPI, a durable PostgreSQL worker,
LangGraph checkpoints, Cloudinary media, Groq transcription/vision, OpenRouter text
generation and FFmpeg rendering. Preserve Overview, Script, Assets, Clips, Publish
and Insights project navigation and existing route URLs. Work remains local.

## Capabilities and Constraints

- Personal and brand scripts, hooks, supporting copy, style profiles, immutable
  history and scoped assistant proposals.
- Private video/image/audio uploads, timestamps, frame evidence, matched/partial/
  unmatched alignment and grounded clip suggestions; manual source selection.
- Trim, captions, crop, title, audio polish and immutable edit versions.
- Six platform presets with safe zones and independent copy for Instagram,
  TikTok, YouTube and LinkedIn. Verified FFmpeg exports remain authoritative.
- Explicit package review, planned dates and manual publication confirmation.
- Computed production metrics and manually sourced performance comparisons.
- No social OAuth/posting, multitrack editing, automatic face tracking, team
  collaboration, billing or in-app recording in this baseline.
- Production session provider is not selected/configured. Existing JWT bearer
  authentication is supported; local demo identity is development-only.

## Brand Commitments

Keep the CreatorAI name. The latest user directive explicitly rejects violet and
requests an Instagram-inspired website: white/ink surfaces, monochrome actions,
warm coral selection accents, and charcoal dark mode. This supersedes the earlier
violet integration-guide palette. The user explicitly requested a sleek modern
redesign using Impeccable, design-taste-frontend, high-end-visual-design,
landing-page-design and Remotion SaaS guidance. Specific aesthetic decisions are
delegated, not claims of an established external brand.

## Evidence on Hand

- `docs/creatorai-build-plan.md` and individual frontend integration guides.
- `docs/backend-verification.md`: 82 automated checks and labelled live-provider
  verification. This is engineering evidence, not a marketing benchmark.
- No testimonials, customer logos, prices, growth statistics or usage claims.
- Generated media/design demonstrations must be visibly labelled illustrative.

## Product Principles

- Keep original source, saved versions and approved publication snapshots intact.
- Show honest state and recovery, not invented progress or performance promises.
- Prefer actual source evidence over forced matches.
- Separate drafts, proposals, saved edits, previews and verified exports.
- Keep secrets and ownership decisions on the backend.

## Accessibility & Inclusion

Design target: keyboard access, clear focus, labelled controls, WCAG AA contrast,
responsive mobile operation, reduced motion and readable English/Hindi/Hinglish.
This is an implementation target, not a certified compliance claim.
