# CreatorAI frontend rebuild

Local-only replacement of the minimal integration UI. The user delegated all
recommended design choices. Product capabilities remain governed by PRODUCT.md
and the build plan; no fake customers, prices, analytics or social posting.

## Direction derivation

Mechanism: connect a saved script to timestamped source evidence, editable recipes
and verified platform exports without destroying the original.
Audience scene: a solo creator editing on a laptop in daylight, then reviewing a
portrait export on a phone. Default light surfaces; a deliberate dark option.
Category ruts excluded: generic gradient AI landing page and its austere dashboard
opposite. Seven ordered cultural systems, spanning interface, print and ritual:

1. Digital contact sheet: scan source and select moments.
2. Post-house call sheet: shared production checklist and handoffs.
3. Broadcast multiview monitor: one source, simultaneous output formats.
4. Creator's annotated script: readable spoken text with evidence margins.
5. Motion festival programme: editorial sequence, preview and selection.
6. Studio equipment catalogue: precise controls and source specifications.
7. Architectural project folio: original material, successive interventions.

Seed `499df743` assigned position 3. Committed world: white and cool silver,
ink typography, violet actions, broad open working surfaces, softly inset major
media trays, synchronized portrait/landscape framing. Geist display and UI.
Signature interaction: Remotion framing previews, followed by authoritative
FFmpeg output. Product navigation remains familiar and task-first.

Challenger hand: film cutting bench identifies strongly with editors but its
coarse grain/industrial orange obscures the pinned sleek violet interface;
pulp paperback rack dramatizes hook alternatives but misidentifies practical
creator production; labanotation exposes timing but introduces an unfamiliar
reading grammar. Each loses on product clarity relative to the assigned monitor.
Streetwear, indoor weather and ANSI BBS remain the reroll pool. Category-standard
layout remains an available user choice, not the recommendation. User's explicit
delegation authorizes this selection without pausing for another question.

## Surface and implementation boundaries

Landing: clear offer, real studio CTA, illustrative multiview, workflow rail,
original-preserving edit demonstration, supported formats and honest FAQ.
Studio: projects, overview, script, assets, clips/editor, publish and insights.
Preserve all existing URLs. Add saved creator style, brand context, assistant
proposal review, manual clip ranges and queued cited insight explanations.
No automatic recording, multitrack edit, OAuth posting or invented signup.

Comps and their prompt/approval sidecars live in `.impeccable/mocks`. Production
photographic media must be independently generated, never sliced from UI comps.
All controls, captions, navigation and text remain semantic interactive code.
Asset producer, independent finish reviewer and documenter are required by the
requested Impeccable skill. DESIGN.md records the actual finished implementation.

## Verification

the user's explicit delegation. Native canvas approximately 1440 by 1100.
